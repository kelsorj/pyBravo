# Authors and credits

OpenBravo is the work of the people below. The public repository starts from a
fresh commit history, so this file — not `git log` — is the record of who built
it.

it exists. See the [README](README.md) for the full dedication.

Others who made the original instrument possible include **Brad Nelson**,
**Dave Assmusen**, and **Chris Shaw**.
